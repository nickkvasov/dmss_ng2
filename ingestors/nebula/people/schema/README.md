# Nebula People Schema Directory

This directory contains generated Nebula Graph schema files for the People ontology (people and roles).

## Files

- `nebula_people_schema.ngql` - Current schema file (generated by default)
- `nebula_people_schema_YYYYMMDD_HHMMSS.ngql` - Timestamped schema files for versioning

## Usage

### Generate current schema:
```bash
cd ingestors/nebula/people
python nebula_schema_generator.py
```

### Generate timestamped schema:
```bash
cd ingestors/nebula/people
python nebula_schema_generator.py --timestamped
```

### Generate schema with custom output:
```bash
cd ingestors/nebula/people
python nebula_schema_generator.py --output schema/custom_schema.ngql
```

## Schema Structure

The generated schema includes:
- Space creation for People data (`people_space`)
- Tag definitions (vertices) for entities:
  - `PERSON` - Individual people with sociographic information
  - `ROLE` - Role classifications (tourist, local, staff, police)
- Edge definitions (relationships):
  - `HAS_ROLE` - Person to Role assignment with metadata
- Indexes for performance optimization

## Versioning

Use timestamped schemas to track changes over time. Each timestamped file includes the generation timestamp in the filename format: `nebula_people_schema_YYYYMMDD_HHMMSS.ngql`

## Integration

This schema works with:
- **People Locations Schema**: For position and location tracking
- **POI Schema**: For Points of Interest data
- **Cross-space queries**: For analyzing people-role-location relationships
