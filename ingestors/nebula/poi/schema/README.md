# Nebula POI Schema Directory

This directory contains generated Nebula Graph schema files for the POI (Points of Interest) ontology.

## Files

- `nebula_schema.ngql` - Current schema file (generated by default)
- `nebula_schema_YYYYMMDD_HHMMSS.ngql` - Timestamped schema files for versioning

## Usage

### Generate current schema:
```bash
cd ingestors/nebula/poi
python nebula_schema_generator.py
```

### Generate timestamped schema:
```bash
cd ingestors/nebula/poi
python nebula_schema_generator.py --timestamped
```

### Generate schema with custom output:
```bash
cd ingestors/nebula/poi
python nebula_schema_generator.py --output schema/custom_schema.ngql
```

## Schema Structure

The generated schema includes:
- Space creation for POI data
- Tag definitions (vertices) for entities
- Edge definitions (relationships) between entities
- Indexes for performance optimization

## Versioning

Use timestamped schemas to track changes over time. Each timestamped file includes the generation timestamp in the filename format: `nebula_schema_YYYYMMDD_HHMMSS.ngql`
