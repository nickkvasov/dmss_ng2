# Nebula People Locations Schema Directory

This directory contains generated Nebula Graph schema files for the People Locations ontology (position and location tracking).

## Files

- `nebula_people_locations_schema.ngql` - Current schema file (generated by default)
- `nebula_people_locations_schema_YYYYMMDD_HHMMSS.ngql` - Timestamped schema files for versioning

## Usage

### Generate current schema:
```bash
cd ingestors/nebula/people_locations
python nebula_schema_generator.py
```

### Generate timestamped schema:
```bash
cd ingestors/nebula/people_locations
python nebula_schema_generator.py --timestamped
```

### Generate schema with custom output:
```bash
cd ingestors/nebula/people_locations
python nebula_schema_generator.py --output schema/custom_schema.ngql
```

## Schema Structure

The generated schema includes:
- Space creation for People Locations data (`people_locations_space`)
- Tag definitions (vertices) for entities:
  - `POSITION_PING` - Raw GPS position events with spatiotemporal attributes
  - `TICKET_ENTRY` - Raw ticket entry events at POI venues
- Edge definitions (relationships):
  - `EMITTED` - Person to PositionPing (person emitted a GPS position)
  - `ENTERED` - Person to TicketEntry (person entered a POI via ticket)
  - `AT_POI` - PositionPing to POI (geospatial association)
- Indexes for performance optimization

## Versioning

Use timestamped schemas to track changes over time. Each timestamped file includes the generation timestamp in the filename format: `nebula_people_locations_schema_YYYYMMDD_HHMMSS.ngql`

## Integration

This schema works with:
- **People Schema**: For person and role information
- **POI Schema**: For Points of Interest data
- **Cross-space queries**: For analyzing movement patterns and attendance
